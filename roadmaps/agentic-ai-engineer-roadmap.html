02

Agentic AI Engineer چیست؟

آشنایی با نقش و مسئله‌ای که این حوزه حل می‌کند

توضیح مقدماتی: یک مدل زبانی بزرگ به‌تنهایی فقط متن تولید می‌کند. Agent مدلی است که به ابزارها متصل شده و می‌تواند جست‌وجو کند، فایل بخواند، API را فراخوانی کند، نتیجه را بررسی کند و گام بعدی را انتخاب کند. مهندس Agentic AI این سیستم‌ها را طوری طراحی می‌کند که درست، اقتصادی و ایمن کار کنند.
این حوزه چیست؟
در Agentic AI یک مدل زبانی بزرگ (LLM) فقط جواب نمی‌دهد؛ هدف را می‌فهمد، مراحل را برنامه‌ریزی می‌کند، ابزار صدا می‌زند، نتیجه را بررسی می‌کند و تا رسیدن به هدف ادامه می‌دهد. مهندس Agentic AI این سیستم‌ها را طراحی، تست و اجرا می‌کند.
Agent چه فرقی با چت‌بات دارد؟
چت‌بات معمولاً یک پاسخ متنی می‌دهد؛ Agent می‌تواند کار انجام دهد: جست‌وجو، خواندن فایل، فراخوانی API و ثبت نتیجه. در تعریف Anthropic، در یک Workflow مسیر را کدِ از پیش نوشته‌شده تعیین می‌کند، اما در یک Agent خودِ مدل مسیر و استفاده از ابزارها را هدایت می‌کند.
چه مسئله‌ای را حل می‌کند؟
کارهای چندمرحله‌ای که قاعده ثابتی ندارند؛ مثل تحقیق و جمع‌بندی، پردازش درخواست‌های پشتیبانی، تحلیل اسناد، رزرو و خودکارسازی فرایندهای داخلی.
چه کسانی معمولاً وارد این حوزه می‌شوند؟
مهندسان نرم‌افزار و Backend، افراد حوزه Data و AI/ML و دانشجویان رشته‌های فنی؛ اما ورود به این حوزه به مدرک یا رشته خاصی محدود نیست و مهارت عملی اهمیت زیادی دارد.
چه زمانی Agent لازم نیست؟
اگر یک Prompt یا یک Workflow ساده مسئله را حل می‌کند، Agent لازم نیست. Agent در ازای انعطاف بیشتر، هزینه، تأخیر و ریسک بیشتری دارد؛ بنابراین بهتر است از ساده‌ترین راه‌حل شروع شود.
زیرحوزه‌های اصلی: Tool Use · Memory / RAG · Planning · Orchestration · Multi-Agent · Testing & Safety · Deployment & Monitoring.
پیش‌نیازها: برای شروع این مسیر پیش‌نیاز اجباری وجود ندارد. آشنایی مقدماتی با برنامه‌نویسی و کار با API روند یادگیری را سریع‌تر می‌کند.

Agentic AI Engineer به‌طور کلی مهندسی است که با استفاده از مدل‌های زبانی، ابزارها و حافظه سیستم‌هایی می‌سازد که بتوانند یک هدف را قدم‌به‌قدم پیش ببرند و نتیجه را قابل اعتماد تحویل بدهند.

Goal→Plan→Tool Call→Observation→Decide→Answer / Repeat

03

AI × Domain

وقتی Agent با یک حوزه تخصصی ترکیب می‌شود

ساخت Agent فقط یک بخش ماجراست. ارزش اصلی زمانی بیشتر می‌شود که مهارت مهندسی Agent با دانش یک حوزه تخصصی (Domain) ترکیب شود؛ مثل سلامت، مالی، حقوق، آموزش، عملیات و نرم‌افزار.

۳.۱ تأثیر AI بر این حوزه

چه چیزی تغییر کرده؟

مدل‌ها در استدلال، استفاده از ابزار و انجام کارهای چندمرحله‌ای بهتر شده‌اند؛ به همین دلیل ساخت Agent از یک آزمایش به یک نیاز کاری نزدیک‌تر شده است.

چه کارهایی سریع‌تر شده‌اند؟

نوشتن نمونه اولیه، خواندن مستندات و تولید کد کمکی با ابزارهایی مثل Claude Code و Copilot سریع‌تر شده؛ اما ارزیابی و دیباگ خروجی هنوز به فهم واقعی نیاز دارد.

چه مهارت‌هایی ارزش بیشتری پیدا کرده‌اند؟

طراحی سیستم، ارزیابی و تست، امنیت، کنترل هزینه و تأخیر، و توانایی تصمیم‌گیری درباره اینکه کجا Agent لازم است و کجا نه.

چه چیزهایی بیشتر در معرض تغییرند؟

Promptهای بسیار پیچیده و کدهای اتصال ساده مزیت پایدار کمتری می‌سازند. فریم‌ورک‌ها هم سریع تغییر می‌کنند؛ پس فهم مفاهیم مهم‌تر از حفظ API یک ابزار است.

۳.۲ کاربردهای Agent در حوزه‌ها

🏥 سلامت

خلاصه‌سازی پرونده و متون پزشکی، پیگیری نوبت و پشتیبانی تصمیم؛ با نظارت جدی انسان.

💰 مالی

پردازش اسناد، بررسی تراکنش‌های مشکوک و گزارش‌سازی؛ اقدام‌های مالی نیازمند تأیید انسان است.

⚖️ حقوق

جست‌وجو در قراردادها، استخراج بندها و خلاصه‌سازی؛ با اهمیت ویژه دقت و کنترل انسانی.

🎓 آموزش

تولید تمرین، بازخورد شخصی‌سازی‌شده و دستیارهای یادگیری.

🏭 عملیات و پشتیبانی

پاسخ به تیکت‌ها، مسیریابی درخواست‌ها و خودکارسازی فرایندهای تکراری.

💻 نرم‌افزار

کمک به کدنویسی، تست، بازبینی کد و مستندسازی.

۳.۳ مهارت‌های جدید

AI Evaluation

تعریف معیار، ساخت مجموعه تست، مقایسه نسخه‌ها و بررسی کیفیت و خطا.

Human-in-the-loop

طراحی نقطه‌هایی که انسان قبل از یک اقدام حساس تأیید می‌کند.

Domain Knowledge

فهم مسئله واقعی یک صنعت و تشخیص اینکه کجا Agent واقعاً ارزش ایجاد می‌کند.

Secure & Responsible AI

توجه به امنیت، حریم خصوصی، شفافیت و ریسک‌های اجرای خودکار.

چرا Domain مهم است؟ Agent خوب بدون شناخت مسئله واقعی به محصول خوب تبدیل نمی‌شود. کسی که هم Agent بسازد و هم فرایند یک حوزه را بشناسد، ابزار درست‌تری انتخاب می‌کند، معیار بهتری تعریف می‌کند و می‌داند کجا باید انسان در حلقه بماند.

۳.۴ مسیر آینده

LLM + Tools+Domain Knowledge→Reliable Workflow→Agent System→Domain Specialist / AI Engineer

مسیر آینده فقط «ساخت یک Agent جذاب» نیست؛ ترکیب Agent با دانش حوزه، ارزیابی، ایمنی و مهندسی سیستم اهمیت بیشتری پیدا می‌کند. داده‌های Stanford AI Index 2026 هم رشد سریع مهارت‌های Agentic AI در آگهی‌های شغلی را نشان می‌دهد (جزئیات در بخش بازار کار).

07

الگوهای طراحی Agent

بعد از فهم اصول، با الگوهای رایج ساخت سیستم‌های Agentic آشنا می‌شویم

🔗 Prompt Chaining

کار به چند مرحله پشت‌سرهم تقسیم می‌شود و خروجی هر مرحله ورودی مرحله بعد است.

🔀 Routing

ورودی طبقه‌بندی می‌شود و به مسیر، Prompt یا مدل مناسب هدایت می‌شود.

⚡ Parallelization

چند زیرکار هم‌زمان اجرا می‌شوند، یا یک کار چند بار اجرا می‌شود تا نتیجه مطمئن‌تر شود.

🎛️ Orchestrator–Workers

یک مدل مرکزی کار را به زیروظایف تقسیم می‌کند و به Workerها می‌سپارد.

♻️ Evaluator–Optimizer

یک مدل خروجی می‌سازد و مدل دیگر آن را ارزیابی و بازخورد می‌دهد؛ این چرخه تکرار می‌شود.

🤖 Autonomous Agent

مدل در یک حلقه خودش ابزار و مسیر را انتخاب می‌کند تا به هدف یا شرط توقف برسد.

یک اصل مهم: پنج الگوی اول Workflow هستند (مسیر را کد تعیین می‌کند) و الگوی آخر Agent است (مسیر را مدل تعیین می‌کند). بهتر است از ساده‌ترین الگو شروع شود و فقط در صورت نیاز واقعی مسئله، پیچیدگی اضافه شود؛ زیرا Agent هزینه و تأخیر بیشتری دارد.

مهارت‌های لازم: طراحی نقش و Handoff، شروط توقف، کنترل هزینه، پروتکل‌های MCP و A2A.

پروژه‌های مناسب: تیم پژوهشگر–نویسنده–بازبین؛ سیستم تحلیل گزارش با چند Agent تخصصی؛ اتصال Agentها با A2A.

بازار آمریکا

روند آگهی‌های شغلی

طبق Stanford AI Index 2026 (بر پایه داده‌های Lightcast)، سهم مهارت‌های Agentic AI در آگهی‌های شغلی آمریکا از 0.06٪ در 2024 به 0.23٪ در 2025 رسید؛ یعنی بیش از 280٪ رشد در یک سال و حدود 90 هزار آگهی. این دسته برای اولین بار امسال به‌عنوان یک خوشه مهارتی مستقل ثبت شده است.

بازه حقوق

طبق Robert Half 2026 Salary Guide، بازه حقوق AI/ML Engineer در آمریکا حدود 134,000 تا 193,250 دلار در سال است. این عدد برای نقش عمومی AI/ML Engineer است، نه مخصوص Agentic AI. Robert Half رشد پیش‌بینی‌شده حقوق شروع را برای AI/ML و علم داده 4.1٪ و بالاتر از میانگین گزارش می‌کند.

مهارت‌های مرتبط

مهارت‌هایی که در این مسیر تکرار می‌شوند و بهتر است در نمونه‌کار دیده شوند: LangGraph، RAG و Vector Database، تست و ارزیابی، مانیتورینگ Agent. در داده‌های Lightcast هم Python پرتقاضاترین مهارت تخصصی AI است و مهارت‌های مرتبط با استقرار (مثل AWS و مقیاس‌پذیری) رشد بلندمدت سریعی داشته‌اند.

توجه: اعداد بالا مربوط به بازار ایالات متحده‌اند و نباید مستقیماً به بازار ایران یا هر کشور دیگری تعمیم داده شوند. رشد 280٪ هم از یک پایه کوچک (حدود 0.23٪ کل آگهی‌ها) اتفاق افتاده است.

بازار ایران

داده‌های این بخش از بررسی مستقیم ۴۰ آگهی/فرصت شغلی مرتبط با Agentic AI به‌دست آمده که در شهریور ۱۴۰۵ از جاب‌ویژن، جابینجا، لینکدین، ایران‌استخدام و ایران‌تلنت جمع‌آوری شده‌اند (۵ مورد در چند منبع تکرار شده‌اند؛ یعنی حدود ۳۵ موقعیت شغلی منحصربه‌فرد).

روند آگهی‌های شغلی

از ۴۰ آگهی بررسی‌شده، ۸۲٪ به‌صراحت LLM، ۶۵٪ عبارت RAG و ۶۰٪ عبارت Agentic را در عنوان یا شرح شغل داشتند؛ ۵۰٪ هم دقیقاً از عبارت «AI Agent» استفاده کرده بودند. ۲۱ مورد (~۵۳٪) در تهران بود و ۱۰ مورد (۲۵٪) امکان دورکاری/ریموت داشت. کارفرماها فقط استارتاپ نبودند؛ شرکت‌هایی مثل علی‌بابا، اسنپ‌باکس، بانک خاورمیانه، پرشیا خودرو، امن‌پردازان کویر (Padvish) و OmidPayment هم آگهی فعال داشتند.

بازه حقوق

از ۴۰ آگهی، فقط ۳ مورد رقم دقیق حقوق اعلام کرده بودند: «متخصص هوش مصنوعی (Agentic AI)» در تهران/ونک ۸۰ تا ۱۲۰ میلیون تومان، «Senior LLM & Agentic AI Engineer» در پردیس ۱۱۰ تا ۱۴۰ میلیون تومان، و «مهندس هوش مصنوعی گفتار» (زیر ۳ سال سابقه) از ۵۰ میلیون تومان. بازه دیده‌شده در این نمونه یعنی ~۵۰ تا ۱۴۰ میلیون تومان در ماه بسته به سطح تجربه. بقیه آگهی‌ها یا «توافقی» بودند یا رقمی اعلام نکرده بودند (یک موقعیت هم دورکاری با پرداخت دلاری بود). این عدد بر پایه فقط ۳ آگهی است، نه میانگین کل بازار.

مهارت‌های مرتبط

درصد آگهی‌هایی که هرکدام را ذکر کرده‌اند: Python ۶۲٪، Vector Database و Docker هرکدام ۲۵٪، LangChain ۲۲٪، LangGraph و Multi-Agent هرکدام ۲۰٪، Fine-tuning ۱۸٪، n8n، FastAPI و CI/CD هرکدام ۱۵٪، Tool Calling ۱۲٪، Prompt Engineering و PyTorch هرکدام ۱۰٪، و MCP (به‌عنوان مهارت نوظهور) ۵٪.

روش پیگیری: در jobvision.ir، jobinja.ir و iranestekhdam.ir با جست‌وجوی عبارت‌هایی مثل «LLM»، «AI Agent»، «RAG»، «LangChain» و «مهندس هوش مصنوعی» و استفاده از فیلترهای «کارآموزی» یا «دورکاری»، می‌توان مهارت‌های تکرارشونده را شناسایی و در Portfolio پوشش داد.

توجه: این آمار از یک نمونه ۴۰‌تایی (جمع‌آوری‌شده شهریور ۱۴۰۵) به دست آمده و آمار رسمی و کامل کل بازار ایران نیست؛ به‌ویژه بازه حقوق فقط بر پایه ۳ آگهی است. ارقام تومانی هم به‌دلیل تورم و نوسان به‌سرعت تغییر می‌کنند و باید در بازه‌های زمانی جدیدتر بازبینی شوند.

چشم‌انداز: تمرکز شرکت‌ها از چت‌بات‌های ساده به سمت Agentهایی می‌رود که بخش بزرگی از یک کار را خودشان پیش می‌برند. در این مسیر، تخصص در یک نقش مشخص (مثل تست و ایمنی، Orchestration یا زیرساخت) معمولاً مهم‌تر از دانستن سطحی همه‌چیز است.
